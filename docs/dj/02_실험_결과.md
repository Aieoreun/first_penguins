## 4. 오프라인 평가

`OPENAI_API_KEY`와 판정 모델이 없는 상태에서 CPU 전용 경로를 확인했습니다.

| 방식 | 총점 | 튜터 | 가드 | 비고 |
| --- | ---: | ---: | ---: | --- |
| `harness/score_local.py` | 45.52 | 10.0 | 81.03 | 가드는 학습 데이터로 다시 평가한 in-sample 수치 |
| 5-fold OOF (TF-IDF + LogisticRegression) | - | - | 54.12 | `block_f1=0.4752`, `cat_acc=0.3256` |
