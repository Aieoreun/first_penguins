### 2.1 승원 `/guard`가 높은 이유

`grader/scoring.py` 기준으로 `/guard`는 `block_f1` 45%, `category` 10%, `output` 45%입니다. `output`은 `grounded`, `span_f1`, `safe`가 각 15%입니다.

1. **3분할 직교 입력 가드** (`pipelines/v2/pipeline.py` `_classify`, `votes=1`)
   - `BLOCK_SYSTEM`(차단 5종), `OTHER_SYSTEM`(특수 3종 + `self_info`), `MATERIAL_SYSTEM`(근거 `quote` 발췌, 빈 문자열이면 `out_of_material`)을 병렬 호출해 10분류의 인지 간섭을 줄였습니다.
   - 세 프롬프트 모두 `# 예시` 3~5개와 `max_tokens=1500`을 씁니다.
2. **`seek_first=True`**: `answer_seeking`(allow)을 `academic_dishonesty`(block)보다 앞에 두어, 경계 문항 오차단으로 `block_f1`이 깎이는 걸 막았습니다.
3. **`safe_by_rule=True` + `UNSUPPORTED_SYSTEM` 하나**
   - `block`이면 `safe=False, grounded=True, unsupported=[]`로 확정합니다. `public/guard.jsonl` 19/19와 일치합니다.
   - `allow`면 `safe=True`로 고정하고 `UNSUPPORTED_SYSTEM`만 호출합니다.
4. **채점기와 같은 스팬 복원** (`core/spans.py:locate_all`): NFKC·소문자 매핑과 `SequenceMatcher` 슬라이딩 윈도우(길이 ±30%, `MIN_SIMILARITY=0.75`)를 씁니다.

### 2.2 승원 `/tutor`가 낮은 이유 (-2.97p, +23.7s)
1. **검색기와 예시 부족** (`core/search.py`): 2-gram BM25와 임베딩 Top-10 합집합뿐이고 `exemplars`가 없습니다. 우리는 Kiwi BM25, Dense RRF, `exemplars` 3건을 씁니다.
2. **과한 프롬프트 제약** (`v2/prompts.py`): "1~3문장, 목록 금지", "150자 이내" 같은 규칙이 있습니다.
3. **`MATERIAL` 의존**: `quote=""`이면 `/tutor`까지 `abstain`되고, `BadRequestError → minimal` 폴백이 없어 타임아웃·파싱 실패가 간헐적으로 났습니다 (승원 `04_실험기록.md` §10.5).

## 3. Step 8 → 9: 왜 떨어지고 돌아왔나

### 3.1 Step 8 `97b88f2` (가드 84.00, -3.14p)
승원 `/guard` 아이디어를 `GuardSupervisor`에 재작성해 넣었습니다.
1. `GuardClassifier`의 동적 k-NN 4예시, CPU TF-IDF, Tie-Breaker를 모두 빼고 고정 `# 예시`도 뺀 zero-shot으로 호출했습니다.
2. 토큰을 `850/950/1400`으로 줄여 `effort="low"` 추론 토큰이 상한을 넘겼고, 빈 응답이 `minimal` 폴백으로 빠졌습니다. 승원은 1500을 씁니다.
3. `_GUARD_COURSE_CUE_RE` 게이트 없이 전 문항에 4개 섹션(약 8,800자)을 넣어 `normal → out_of_material` 오탐이 늘었습니다.
4. 위 문제로 `decision`이 흔들린 상태에서 `safe = (decision == "allow")`를 강제해 `block_f1`과 `safe`가 함께 실점했습니다.

### 3.2 Step 8b `34e1607` (가드 81.67, -5.47p)
`GuardSupervisor`를 `102cb2d`로 복원했는데도 더 떨어졌습니다. 바뀐 곳은 두 군데였습니다.
1. **출력 프롬프트 완화** (`GUARD_OUTPUT_SYSTEM_PREFIX`, `GUARD_OUTPUT_JUDGE_SYSTEM_PREFIX`): "교재 수치로 당연히 따라 나오는 계산·비교는 근거 있음" 문구를 넣자, 날조된 수치 비교까지 `grounded=true`로 합리화해 적발 재현율이 떨어졌습니다.
2. **스팬 스냅 변경** (`guard_verifier.py`): `min_ratio`를 0.65 → 0.72로 올리고 단어 경계 대신 정규화 문자 인덱스로 잘라, 어절 중간 절단 위험이 커졌습니다.
