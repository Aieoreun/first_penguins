# 가드 요청 시간 예산과 운영 기록

판정 프롬프트, 검색 top-k, 모델 토큰 한도는 유지한다. server 기본 검토 설정은 OFF다.

- `guard_runtime.py`는 요청별 ContextVar로 20초 1차 deadline과 랜덤 추적 ID를 전달한다. 메타데이터 로그는 질문·답변·모델 출력·예외 본문을 포함하지 않는다.
- 실제 후보 문장 번호만 grounding_decision JSON schema의 enum으로 허용하고 Python으로도 검사한다.
- 근거 선택 뒤 구간 추출은 요청의 남은 시간에서 0.25초를 예약한다. 1초 미만이면 호출을 생략하고 이미 선택된 오류 문장을 사용한다. 미확정 근거 판정은 생성하지 않는다.
- 실패한 단계만 최대 1회 재시도한다. 직전 시도 시간과 최소 2초를 기준으로 남은 예산을 확인하고 토큰 소진은 동일 요청 재시도를 생략한다. 완료된 다른 단계와 요청 내 검색 결과는 재사용한다. 요청 종료 후 결과를 보관하거나 다른 요청에 캐시하지 않는다.
- `X-Guard-Request-ID`와 `guard_event` 로그로 단계별 실패를 연결한다. 모델 호출 success는 전송 완료를 의미하며 최종 검증 성공과는 다르다. `model_response.finish_reason`, 상위 단계 failure 및 request success/failure를 함께 확인한다.
- 모든 필수 판정이 완료되면 기존 JSON 응답을 반환한다. 필수 단계가 미완료면 503이며 추정값으로 성공 응답을 만들지 않는다.

공개 HTTP 평가: 환경변수를 읽은 상태에서 `python tools/evaluate_guard_budget.py --root <코드 스냅샷 절대경로> --destination <새 결과 폴더> --workers 64 --repeats 3`.
스냅샷에는 실행 Python 파일, kb/, public/, harness/, grader/, work/kb_index.json이 필요하다. 도구는 매회 새 server:app을 실행하고 검토 OFF를 강제하며 실행한 서버만 종료한다. 공개 데이터 정답은 서버/LLM에 전달하지 않는다.
