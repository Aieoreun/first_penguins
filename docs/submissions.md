# 제출 기록

제출(운영진 채점)과 로컬 채점 결과를 한 표에 남긴다. 제출 한 번에 한 줄. **마지막 날 어느 커밋을 누가 낼지 정하는 근거**가 되므로 제출했으면 바로 적는다.

규칙

- `커밋 해시`는 제출 시점에 서버에 떠 있던 코드의 해시(`git rev-parse --short HEAD`)이고 `submission.json`의 `commit`과 같은 값이다. 이 표를 고치는 커밋은 코드 변경과 섞지 않는다.
- 점수와 오류 수는 제출 결과 메시지를 그대로 옮긴다. `seed`도 적는다 (운영진 감사용).
- 로컬 점수는 같은 커밋으로 `harness/score_local.py`를 돌린 총점. 판정 모델 없이 돌렸으면 `(판정 없음)`을 붙인다.
- 채점 요청·답변 본문은 적지 않는다 (SPEC.md §8). 공개 세트 문항 ID와 틀린 항목은 적어도 된다.
