## 출력 구성요소의 통제 비교

같은 v2/v4 입력 경로도 실행별 차단 F1이 달라져 출력의 효과를 분리하기 어렵다. `jh_output_replay.py`는 `jh_full_v4/v4_1`의 **자체 입력 예측**을 고정하고, 공개 대화와 BM25 top1 검색을 재현하여 후보의 출력 검사만 호출한다. 예측 category/decision이 보존되는지 검사한다. 정답 입력 라벨은 상태 생성에 쓰지 않는다. 이 값은 출력 진단이며 전체 HTTP 평가나 비공개 점수로 취급하지 않는다.

```bash
.venv/bin/python experiments/jh_output_replay.py --source experiments/.cache/jh_full_v4/v4_1 --variant jh_v4_safety --name safety_fixed_1 --workers 16
```

고정 입력 출력 진단 1회: 원래 v4 87.79, `jh_v4_safety` 88.29. 두 실행 모두 입력 F1 0.8696 / 범주 정확도 0.8721로 동일하다. 그러나 같은 근거 알고리즘도 grounded 0.9070→0.9186, span 0.7787→0.8122로 흔들렸고, 안전성은 0.9767→0.9651로 낮아졌다. 0.50점 상승을 안전 검사 개선으로 해석하지 않는다. 원래 end-to-end v4의 89.17과도 출력 재실행 변동이 있으므로 작은 차이는 반복 확인한다.

## 자체 분류기 탐색 — 미채택

### 공개 범주로 처음부터 학습하는 후보

`c057633`의 `jh_learned_gate`는 SPEC 7.1에서 허용한 자체 학습 분류기다. 서버 시작 시 공개 tutor·guard의 마지막 사용자 발화와 **범주 라벨만**으로 char TF-IDF + LogisticRegression을 처음부터 학습한다. 질문→답 표, 문항 ID 비교, reference_answer, 응답 캐시를 사용하지 않는다. 새 요청은 학습에 추가하지 않는다. 별도 사전 학습 모델이나 외부 데이터도 없다.

C=1000, min_df=2, char 2~5gram, max_features=60000, balanced 클래스 가중치다. 모델 출력 확률(보정되지 않음)이 기준 이상이면 학습 분류를 쓰고 나머지는 adaptive로 처리한다. harmful_content는 세부 action을 구별할 수 없으므로 항상 기존 LLM 판정으로 넘긴다. 기준 0.995 / 0.98 / 0.95를 각각 `jh_learned_gate` / `jh_learned_gate98` / `jh_learned_gate95`로 구분한다. 추가 의존성은 `requirements-jh-research.txt`에 있다.
