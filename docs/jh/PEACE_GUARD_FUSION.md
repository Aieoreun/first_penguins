## 구조와 변경 의미

검색 뒤 입력 판정, 후보 답변의 근거 검사 5회, 독립 안전성 검사를 동시에 시작한다. 입력 판정은 기존 로지스틱 회귀 fast path를 유지하고, LLM fallback에서는 Peace처럼 block/other 투표 뒤 material 판정을 한다. 전체 가드 시간은 슬롯 대기 포함 28초다. ground/safety는 각 13초, 입력 준비는 26초 범위 안에서 실행한다.

근거 검사 일부가 제한 시간에 걸려도 완료된 투표만 합의에 사용하고, 우리 span 모델로 선택된 오류 구절의 경계를 보정한다. 입력이 BLOCK이면 기존 규격대로 grounded=true, unsupported=[]로 병합한다. 안전성은 별도 상태에서 구하며 grounding의 safe 값으로 덮어쓰지 않는다. 기존 refusal review를 독립 safety 검사로 대체하는 것이므로 단순한 병렬화 실험은 아니다. 외부 취소와 시간 초과 때 모든 하위 작업을 취소·회수한다.

`jh_pg_requested`는 fusion의 guard fallback BLOCK 프롬프트만 Peace 최신 requested_action 버전으로 바꾼다. calibrated 추가 경계 문장까지 포함한 원본 SHA256은 `2bd470807c6ddaa1d87442f2b1f809398d986d72094c89735e51aa69206a709f`다. `_block_system`을 endpoint 표식으로 분기해 tutor에는 적용하지 않는다. 학습 모델이 확정한 입력은 여전히 프롬프트 호출을 하지 않으므로 이 변경의 적용 범위는 fallback에 한정된다.

첫 safety 오답 5개는 방어 원리 설명·가상 피해 사례·문자열 출력/연결 실습·사기 예방 설명이다. 단어의 위험성이나 숙제 표현을 실제 위험 수행/완성 제출물 대행으로 확대 해석했을 가능성이 있다. 후속 safety에서는 후보가 실제 수행한 행동과 위험 문장의 역할(설명/인용/권유)을 명시적으로 구분하는 가설을 검토한다. 문항 ID나 질문별 답 표는 사용하지 않는다.
