## 최종 선택

**제출 우선 후보는 B `jh_r7_binary_guard` 유지**, 복귀 후보는 A `jh_cm_char_mlp50`이다. 기본 파이프라인을 자동 변경하지 않았다. 이번 R8에서 새로운 실제 제출 점수는 받지 않았다. 사용자가 확인한 B 후속82.30(가드86.60·81.979초)도 삭제하지 않고 별도 보존했다.

새 후보의 안정적인 전체 점수 상승을 확인하지 못했다. 다음에 실제 제출을 한 번 더 시험한다면 **`jh_r8_output_veto`를 탐색 후보**로 남긴다. B의 입력·튜터·근거 검사는 그대로 두고, 기존 unsafe 판정을 유지하면서 공개 후보 답변으로 학습한 문자 LR의 높은 위험 신호(.9)만 추가한다. 추가 GPT/임베딩 호출은 없다. 로컬 m01 가드95.02→95.75, g08 95.10→95.88이었지만 실제 제출 개선은 미확인이다. 학습과 겹친 후보의 교정 효과가 포함되고 새 표현60에서는 발동0이었다.

## 보존한 주요 후보와 한계

- `jh_r8_binary_ground3`: B 근거 투표5→3회. 가드196 두 비교에서+.77/+.44, 다른 표현60에서+.71이었다. 혼합 m01 가드 차이는+.04이고 지연 이득도 매번 반복되지 않았다.
- `jh_r8_binary_adaptive`: 첫2표가 같으면 종료, 다르면3표 추가. 호출은 줄었지만 두 반복 모두 B보다 느렸다.
- `jh_r8_quantity`: 실제 금액·비율·기간·회수·포인트 등 수치와 단위가 있는 질문에만 계산 설명을 추가한다. 학년 숫자로 일반 질문에 잘못 발동하던 경로를 좁혔다. 다른 표현 튜터181개에서는 아직 직접 비교하지 않았다.
- `jh_r8_span_veto`: 공개 학습형 구절 모델이 모든 문자에서 .95 이상일 때만 놓친 근거 오류를 추가한다. 학습 후보에서는 교정했지만 grouped OOF 오류35개 탐지0, 새 표현·관계 자료에서 발동0이었다. 일반화 개선을 주장하지 않는다.
- `jh_r8_local3`: 근거3회+출력 veto+구절 veto 결합. `jh_r8_local3_quantity`는 수치 설명도 결합한다. 위 반복 결과로 기본 승격하지 않는다.
- `jh_r8_resilient_guard` / `jh_r8_resilient_both`: 실제 검사 실패 때만 입력·근거의 로컬 대체를 적용한다. 후자는 튜터 입력 완전 실패도 보완한다. 실패 주입에서는 효과가 있었지만 정상 실행 대체0회였으므로 정상 점수 개선으로 해석하지 않는다.
- `jh_r8_fixed_harmful` / `jh_r8_brief_harmful`: harmful 튜터 응답만 범주별 정책 문장으로 고정한다. 입력·가드 유지. 고정 구성요소 점수95.05→95.05/93.49여서 채택하지 않는다. 전체 HTTP 실행은 미측정이다.

숫자32 개발 자료에서 질문 값 강조 후보90.10 대 B78.91이었지만, 일반 혼합에서는 반복 이득이 없었다. 일부 수작업 문항에 실제 상품 납입 한도와 가정 계산의 모호성도 확인했다. 예측을 본 뒤 gold를 고치지 않았으며 이 +11.19를 실제 제출 개선량으로 제시하지 않는다.

출력 임베딩 LR/MLP, 단어 특징, 정규화, margin/entropy 게이트, 클래스 가중치·앙상블·문맥 라우팅 등 채택하지 않은 가설도 모두 [작업 기록](ROUND8_IMPROVEMENTS.md)과 개별 JSON에 남겼다. 출력 임베딩은 OOF 일부 개선이 있었으나 기존 문자 후보 대비 개발 응답 추가 교정이 없고 호출 비용이 늘어 배포 자산을 추가하지 않았다.

## API·검증·보존 상태

중단 전에는 대량502/timeout 구간이 있었다. 재개 시 단일·순차3회·동시8회가 모두 성공했고 이후 비교에서 대량 장애는 재현되지 않았다. 소수의 내부 timeout/파싱 오류는 남았다. **공식 오류0은 내부 API 오류0을 뜻하지 않는다.** g02/g05/numeric01을 정상 성능 순위에서 제외하는 이유와 불리한 관측도 보존했다.

- 전체1003테스트 통과, diff 공백 검사 통과.
- 기준 `6ec111d` 대비 `core`, `grader`, `harness/score_local.py`, `server.py`, `SPEC.md`, `public`, `kb` 변경0.
- .env·비밀키를 변경하거나 커밋하지 않았다. 비스트리밍, 기존 요청 예산과 기존 A/B 유지.
- 완료 일반 비교61후보 실행·10,858응답. 집계에는 장애 표시된 g02도 포함한다. 중단 g05와 numeric01은 별도 보존하며 정상 평균에 섞지 않는다.
- 원 응답과 개발 캐시는 무시 경로 `experiments/.cache`에 보존한다. 비공개 테스트 본문을 수집·학습하지 않았다.
- 로컬 커밋만 작성했다. 비교/진단/uvicorn 잔여 프로세스는 없다.
