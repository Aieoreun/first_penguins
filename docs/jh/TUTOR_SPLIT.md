## 구현과 비교 조건

- `jh_r2_tutor_split`: /tutor는 DenseTen 인스턴스, /guard는 상속한 ContextFast 경로 그대로.
- candidate_answer 유무로 경로를 고르지 않는다. 평가인지 감지하는 분기는 없다.
- 두 인스턴스가 요청 semaphore 하나를 공유하여 합산 동시성이 64를 넘지 않는다.

- 기준선과 후보 모두 embedding env, HTTP/내부 64, judge 32. 주최측 평가기·공개 자료·교재는 그대로다.

## 후속 판단 기준

## 후속 가설: 일반 답변 검토

이전 공개 응답에서 올바른 섹션을 찾고도 질문에 필요한 사실을 빠뜨리거나,
주변 설명·추측을 덧붙인 사례를 확인했다. 이전 evidence-first 방식은 교재 원문과
정확히 일치하는 인용 문자열을 요구하다 검증 실패가 많았으므로 같은 방식을 반복하지 않는다.

`jh_r2_answer_review`는 기존 contextfast의 정상·개인정보 포함 학습 답변 초안만 교재와 대조한다.
수정 불필요면 원문을 유지하며, 추가 검토는 low/최대 2000토큰/7초이고 요청 마감 전 .5초를 남긴다.
남은 시간이 3초 미만이면 생략한다. 실패 시 사용 가능한 원래 답변·인용을 유지한다.
가드, 입력 판정, 근거 선택, 거절·정답 요구·제출 대행 경로는 바꾸지 않는다.

먼저 `jh_answer_review_probe.py`로 기존 공개 응답의 자체 action·citation·초안을 고정해 진단한다.
참고 교재는 기존 응답이 인용한 섹션이며 정답 evidence나 category를 주입하지 않는다.
동일한 공개 판정 호출만 기존 journal에서 재사용한다. 7초는 검토 단계만의 제한이므로

## 정답 요구의 근거 사실·계산 발판 강화

승원 브랜치의 주최측 답변 기록과 이전 공개 answer_seeking의 사실 누락을 근거로,
`jh_r2_factual_scaffold`는 해당 범주의 답변 프롬프트만 바꾼다.
기존 프롬프트도 교재 사실을 알려 주도록 했지만, 새 후보는 관련된 분류 항목을 빠뜨리지 않고
질문에 필요한 간단한 계산의 식과 결과를 보여 준 뒤 선택·이유 설명을 학생에게 맡긴다.
선택지 번호만 답하거나 제출 답안 전체를 대신 쓰도록 지시하지 않는다. 정답표나 질문별 분기는 없다.
입력 분류·교재 선택·guard·다른 tutor 범주는 기존 contextfast 그대로다.

공개 원본과 기존 변형의 해당 범주를 별도로 선정해 구성요소 진단한다.
범주 라벨은 평가 자료 선택에만 쓰고 HTTP 본문에는 보내지 않는다. 런타임은 자기 판정으로 경로를 선택한다.
집계에 category_filter를 남기며 소수 범주 점수를 전체 점수로 해석하지 않는다.

## 교재 질문에서 근거 선택과 생성 지시 비교

정상 답변의 사실 누락·주변 설명 문제에 대해 `jh_r2_english_answer`는 일반 학습 답변의 지시만

입력·근거 선택·guard·정책 응답·low/2000토큰 설정은 그대로다. 모델이 지시 언어에 다르게 반응하는지 측정한다.

이전 source_choice는 BM25-only에서 교재 질문에는 도움이 됐으나 전체 비교의 이득이 불안정했다.
현재 실전 기준은 env이므로, 기존 contextfast/env·source_choice/env·english_answer/env를
기존 교재 유래 57문항에서 비교해 근거 선택과 생성 지시 효과를 분리한다.
57문항은 이미 사용한 개발 자료이며 새 holdout이라고 부르지 않는다. 학습이나 예시 색인에는 넣지 않는다.

## 실행 및 비교 재현

프로젝트 루트와 기존 `.venv`, 임베딩 환경변수를 갖춘 `.env` 기준이다.
분리 후보를 실행하려면:

```bash
.venv/bin/python experiments/jh_server.py \
  --variant jh_r2_tutor_split --embedding-mode env \
  --request-slots 64 --host 0.0.0.0 --port 8000
```

기존 후보는 variant를 `jh_guard_fitted_contextfast`로 바꾼다.
영어 답변 지시문 실험 후보는 `jh_r2_english_answer`다. 나머지 조건은 동일하다.
`jh_r2_dense10`은 guard까지 바뀌는 이전 후보이므로 요청한 분리 후보와 혼동하지 않는다.

다음 명령은 공개 원본을 수집해 로컬 비교하는 명령이며 비공개 제출이 아니다.
실험 이름은 실행마다 새로 정한다. 원래 API 채점기는 수정하지 않았다.

```bash
.venv/bin/python experiments/jh_compare.py \
  --name split_reproduction_1 \
  --variants jh_guard_fitted_contextfast jh_r2_tutor_split \
  --repeat 2 --embedding-mode env --workers 64 \
  --request-slots 64 --judge-workers 32 --collect-only
```

그 뒤 생성된 각 `experiments/.cache/jh_split_reproduction_1/<variant>_<repeat>`에 대해
`experiments/jh_resume_score.py <run-directory>`를 실행한다.
변형·교재 진단의 기존 응답/판정 캐시는 로컬 ignored 경로이고 저장소에는 집계와 해시를 보존한다.
새 체크아웃에서 원본 비교는 가능하지만 파생 진단의 완전 재현에는 해당 생성·검토 캐시도 필요하다.
