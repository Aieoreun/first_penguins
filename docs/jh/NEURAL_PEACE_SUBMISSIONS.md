## 차이와 해석

- F−A: 총점−0.41, 튜터+0.83, 가드−1.65, 소요 시간−5.518초. F가 이번에 더 빨랐지만 가드 점수 상승은 확인되지 않았다.
- C−A: 총점−0.76, 튜터−1.83, 가드+0.31, 소요 시간+2.856초. 이번 세 후보 중 C의 가드 점수가 가장 높다. 다만0.31점 차이와 단회로 안정적인 우위는 주장하지 않는다.

F/C의 튜터 구현은 동일하다. 튜터 점수 차이를 새로운 튜터 설계의 차이로 해석하지 않는다. 서로 다른 비공개 seed/자료, 모델 생성·판정 변동, 공유 API 부하가 영향을 줄 수 있으며 현재 집계만으로 원인을 나눌 수 없다. C의 가드 상승이 독립 안전성 검사 덕분인지, timeout 조정인지, 표본 변동인지는 이 결과만으로 확정할 수 없다. 실제 제출에는 구성요소별 오탐·미탐 내역이 없다.

공식 오류0은 서버 내부 timeout0을 뜻하지 않는다. F의 로컬 혼합 실험에서 guard timeout0/392를 관측했지만 이번 실제 제출에서 재확인한 것은 아니다. 실제 제출 점수와 [로컬36회 비교](NEURAL_PEACE_GUARD.md)의 점수를 합산하거나 평균내지 않는다. Peace의 실제 가드90점 초과 및 공개 평균90.52도 별도 근거로 유지한다.

## 갱신한 추천

1. **최종 보존 후보 A 유지:** 현재 관측 총점 최고85.41. 재실행 시 같은 점수가 보장되지는 않는다.
2. **다음 검증 우선순위는 C와 A 반복 비교:** C의 가드89.88은 유망한 신호다. 같은 환경·slots64에서 A/C를 번갈아 추가 제출하고 총점·튜터·가드·Duration·seed를 함께 기록한다. 각2~3회 이상 관측해도 통계적 우위를 자동 보장하지 않지만 단회보다 판단 근거가 늘어난다. 새 API 실험이나 제출은 이 결과 기록 작업에서 실행하지 않았다.
3. **F는 보조 후보로 보존:** 로컬 timeout 감소와 이번 짧은 Duration은 장점이지만 가드87.92로 점수 개선 근거는 약하다. 제출 전의 F 우선 추천을 고정하지 않고 새 실제 결과를 반영한다.

같은 계정에서 위 순서로 제출했다면 마지막 제출은 C의84.65다. 과거 최고85.41은 관측 기록이며 자동 유지되는 최종 점수로 간주하지 않는다.
