앞서 받은 이진 가드2회와 별도 집계한다. 수신 순서는 B1→A1→B2→A2다. B1/A1은 사용자 명시이며 B2/A2는 후보명이 생략되어 직전 실행 안내로 잠정 대응했다. 정정 시 재분류한다. 제출 시각·실제 실행 커밋·시작 로그·내부 오류는 미확인이다. 안내 커밋은 b537de3이다.

각2회 평균에서는 B가 가드+2.31·총점+.66 높고 시간은+.049초로 비슷했다. 가드 개선 가능성을 지지하는 관측이지만 B 가드91.59→89.20의 큰 변동과 적은 반복 수 때문에 안정적 우위는 미확정이다. 튜터 구현은 동일하며 평균−1.00을 튜터 코드 변경의 효과로 설명하지 않는다. 부하·문항 구성·모델 출력·채점·내부 실패의 기여는 집계만으로 분리할 수 없다.

사용자 결정에 따라 각2회에서 교대 비교를 종료하고 **B `jh_r7_binary_guard`를 우선 제출 후보로 채택**한다. A `jh_cm_char_mlp50`는 복귀용으로 보존한다. 평균 총점+.66·가드+2.31과 비슷한 평균 시간을 운영상 선택 근거로 삼으며 통계적 우위 확정과 구분한다. B3/A3 추가 반복 계획은 취소한다. 실행 코드·기본값·런박스 서버를 변경하거나 새 API 실험을 시작하지 않았다.

B1 총점85.96/가드91.59는 공유된 최고 관측치로 보존한다. 앞선 별도 B2회는 이번 교대 평균에 섞지 않는다. [새 비교 원기록](round7_ab_repeat_submissions.json).

## 이전 이진 가드 2회 기록과 당시 판단

직전 실행 안내와 대화 맥락에 따라 두 결과를 `jh_r7_binary_guard`로 기록했다. 실제 시작 로그·실행 커밋·모델 설정은 별도로 확인하지 않았다. 안내 커밋은 `b537de3`이며 제출 시각은 미제공이다.

현재는 가드 평균이 소폭 높고 총점 평균은 비슷하다. 로컬 세 번의 평균 가드 상승 +1.787이 비공개에서도 재현됐다고 말할 근거는 없다. 반대로 두 번만으로 실패나 동등성을 확정할 수도 없다. 이번 두 가드는 기존 A의 관측 범위86.84–89.83 안에 있다.

두 제출 사이 총점은+.90, 튜터는+2.25, 가드는−.47이었다. 같은 튜터 코드에서도 점수가 크게 달라져 단회 총점만으로 가드 후보를 평가하기 어렵다. seed별 구성·모델 출력·판정·부하·내부 실패의 기여는 집계만으로 구분하지 못한다.

Duration 평균은 과거 A보다7.864초 짧지만 같은 시점의 대조가 없어 속도 개선의 인과 근거로 삼지 않는다. 실제 요청 지연 분포도 알 수 없다.

운영 추천은 기존 A 보존, 이진 가드는 비교 후보 유지다. 추가 제출을 한다면 같은 코드·환경에서 A와 이진 가드를 번갈아 실행해 각 후보의 결과를 빠짐없이 기록한다. 새 로컬/API 실험은 재개하지 않았다.
