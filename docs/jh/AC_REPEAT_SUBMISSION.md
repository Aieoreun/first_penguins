# A/C 실제 제출 5회씩 비교

상태: 결과10/10회 수신 완료. A/C 각5회이며, 실행명이 생략된 마지막 두 결과는 직전 안내 순서로 A5/C5에 잠정 대응했다. 이번 비교의 운영 추천은 A(`jh_cm_char_mlp50`) 유지, C는 보조 후보 보존이다. 이전 단회 제출과 로컬 점수는 이번 통계에 포함하지 않았다.

- A: `jh_cm_char_mlp50`
- C: `jh_np_timeouts`
- 순서: A1 → C1 → A2 → C2 → A3 → C3 → A4 → C4 → A5 → C5.
- 앞 제출 채점이 끝나고 결과를 기록한 후 서버를 Ctrl+C로 종료하고 다음 후보를 시작한다. Application startup complete 확인 후 제출한다.
- 동일 런박스·커밋·환경변수·의존성·embedding env·slots64 유지. 비교 도중 코드 업데이트/튜닝 없이 진행한다. 기존 F/C/D 실행 코드 b776679에 두 후보가 모두 들어 있다.
- 비교 중 별도 API 실험을 함께 실행하지 않는다. 팀의 공유 API 부하는 통제하지 못할 수 있으므로 제출 시각과 특이 사항을 남긴다.
- 실패·낮은 점수도 모두 기록한다. 제출 실패로 점수가 없으면 NA와 사유를 남기고 추가 실행은 별도 번호로 표시한다. 불리한 결과를 조용히 대체하지 않는다.
- 요청/응답 본문은 수집하지 않는다. 집계 결과, 시각, 비내용 오류 종류·개수만 기록한다.

## 시작 전에 한 번

기존 서버를 종료한 뒤 현재 커밋·환경 설정을 확인한다. 아래 환경 확인 도구는 키/토큰 값을 출력하지 않는다.

```bash
cd ~/first_penguins_jh
git rev-parse HEAD
git status --short
.venv/bin/python experiments/jh_environment.py
```

커밋과 환경 확인 결과를 공통 메모에 남긴다. 이전 C/D 제출과 코드·주소·토큰이 같다면 submission.json 변경은 필요 없다. 값이 바뀌었다면 첫 제출 전에 일치시킨다.

```bash
cd ~/first_penguins_jh
.venv/bin/python experiments/jh_server.py \
  --variant jh_cm_char_mlp50 \
  --embedding-mode env \
  --request-slots 64 \
```

**운영 추천은 A `jh_cm_char_mlp50` 유지다.** 평균 총점+0.866, 가드+0.734이며 총점 중앙값84.81 대83.61, 가드 중앙값88.61 대87.61도 A가 높다. C는 평균0.7028초 빠르지만 이번 점수 우선 목적에서 A를 교체할 근거가 부족하다. C는 가드 최고90.45를 기록한 보조 후보로 보존한다. 통계적 우위는 미확정이며 실제 운용 후보 선택과 구분한다.

A의 튜터 평균도0.998점 높았지만 두 후보의 튜터 구현은 같다. 따라서 총점 차이 전부를 가드 설계 효과로 설명할 수 없다. 표시된 구성 점수 기준으로 총점 차이는 튜터0.499 + 가드0.367 =0.866이다. seed·모델 생성/판정·공유 부하·실제 환경 차이를 현재 집계로 분리하지 못한다. 실행 커밋·시작 로그도 독립 검증하지 않았고 제출 시각은 첫 두 건만 제공됐다.

## 분석 기준

주 판단 지표는 가드 점수이며 총점·튜터·지연도 함께 본다. 후보별 평균·중앙값·표준편차·최저/최고, 오류 수를 계산한다. 인접 A/C 쌍의 차이도 표시하되 서로 다른 seed이므로 같은 문항에 대한 paired test로 취급하지 않는다. 같은 순서의 교대는 장기 시간대 편향을 줄이는 데 도움을 줄 뿐, 순서 효과나 표본 차이를 제거하지 못한다. 5회는 시작 표본이다. 이번에는 통계적 우위를 미확정으로 남기고, 관측 평균·중앙값에 근거해 기존 A를 운영상 유지한다. 추가 비교는 별도 요청 시 검토한다.

최고점만 고르거나 기존 유리한 단회 결과를 이번5회 평균에 섞지 않는다. 같은 계정의 최종 점수는 마지막 제출이며, 이 순서에서는 C5가 마지막이다. 이번 비교 후 보존 후보는 A 유지로 판단했으며, 실제 최종 제출은 사용자가 별도로 진행한다.
