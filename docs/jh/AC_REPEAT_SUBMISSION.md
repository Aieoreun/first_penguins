# A/C 실제 제출 5회씩 비교

상태: 사용자 보고 A1/C1/A2/C2/A3/C3 수신(6/10회). A 3/5회, C 3/5회. 다음 순서는 A4이다. 기존 단회 제출은 이 묶음의5회에 포함하지 않고 별도 참고 자료로 유지한다.

- A: `jh_cm_char_mlp50`
- C: `jh_np_timeouts`
- 순서: A1 → C1 → A2 → C2 → A3 → C3 → A4 → C4 → A5 → C5.
- 앞 제출 채점이 끝나고 결과를 기록한 후 서버를 Ctrl+C로 종료하고 다음 후보를 시작한다. Application startup complete 확인 후 제출한다.
- 동일 런박스·커밋·환경변수·의존성·embedding env·slots64 유지. 비교 도중 코드 업데이트/튜닝 없이 진행한다. 기존 F/C/D 실행 코드 b776679에 두 후보가 모두 들어 있다.
- 비교 중 별도 API 실험을 함께 실행하지 않는다. 팀의 공유 API 부하는 통제하지 못할 수 있으므로 제출 시각과 특이 사항을 남긴다.
- 실패·낮은 점수도 모두 기록한다. 제출 실패로 점수가 없으면 NA와 사유를 남기고 추가 실행은 별도 번호로 표시한다. 불리한 결과를 조용히 대체하지 않는다.
- 요청/응답 본문은 수집하지 않는다. 집계 결과, 시각, 비내용 오류 종류·개수만 기록한다.

## 시작 전에 한 번

기존 서버를 종료한 뒤 현재 커밋·환경 설정을 확인한다. 아래 환경 확인 도구는 키/토큰 값을 출력하지 않는다.

```bash
cd ~/first_penguins_jh
git rev-parse HEAD
git status --short
.venv/bin/python experiments/jh_environment.py
```

커밋과 환경 확인 결과를 공통 메모에 남긴다. 이전 C/D 제출과 코드·주소·토큰이 같다면 submission.json 변경은 필요 없다. 값이 바뀌었다면 첫 제출 전에 일치시킨다.


## 수신 결과 메모

- A1은 사용자 명시 후보 A(`jh_cm_char_mlp50`)로 기록했다. 제출 시각은 사용자가 KST로 제공한 `2026-11-19T18:09:54`를 그대로 보존했다. 보고일을 제출일로 덮어쓰지 않는다.
- 600요청, 공식 시간 초과·형식 오류/응답 없음·판정 오류 모두0. 서버 내부 오류는 미확인, 특이 사항은 미기재다. 실행 커밋·모델·환경·시작 로그는 아직 확인하지 않았다.
- 기존 A 단회85.41 대비 총점−0.25, 튜터−0.17, 가드−0.32, Duration+0.877초. 이전 결과는 이번 반복5회 통계에 포함하지 않는다. 단회 차이로 회귀나 안정성을 확정하지 않는다.
- C1은 사용자 명시 후보 C(`jh_np_timeouts`)로 기록했다. 제출 시각은2026-11-19 18:12:59 KST,600요청·공식 오류0. 서버 내부 오류·실행 커밋·모델·환경·시작 로그는 미확인이다.
- 첫 인접 비교 C1−A1: 총점−1.55, 튜터−0.75, 가드−2.36, Duration−0.377초. 이번 관측에서는 A가 점수에서 앞섰고 시간 차이는 작았다. 각1회·다른 seed라 안정적인 우열이나 변경의 원인을 확정하지 않는다. 튜터 구현은 동일하므로 튜터 차이를 설계 차이로 설명하지 않는다.
- 기존 별도 C 단회89.88 대비 이번 가드86.89는−2.99다. 변동의 관측이며 원인을 현재 집계로 분리할 수 없다. 이전 C 결과도 이번5회 평균에 섞지 않는다.
- A2는 사용자 명시 후보 A로 기록했다. 제출 시각은 미제공이므로 추정하지 않고 비워 둔다. 600요청·공식 오류0이며 내부 오류·실행 환경은 미확인이다.
- A2−A1: 총점−0.82, 튜터+0.75, 가드−2.41, Duration−1.010초. 같은 A에서도 첫 A1/C1 가드 차이2.36보다 큰2.41의 변동이 관측됐다. A2 가드86.84와 C1 가드86.89 차이는−0.05다. 이것이 원인을 입증하거나 후보가 동등하다는 뜻은 아니지만, 첫 차이를 후보 효과로 단정할 근거는 부족하다.

## 현재 누적 평균

이번 반복 묶음의 후보별3회 중간 집계다. 기존 단회 최고점이나 로컬 점수는 포함하지 않는다.

|후보|횟수|총점 평균|튜터 평균|가드 평균|Duration 평균 초|

표준편차는 n−1 분모의 표본 값이다. n=3이라 변동성 추정은 불안정하며 현재 값으로 후보의 안정성을 확정하지 않는다.

## 분석 기준

주 판단 지표는 가드 점수이며 총점·튜터·지연도 함께 본다. 후보별 평균·중앙값·표준편차·최저/최고, 오류 수를 계산한다. 인접 A/C 쌍의 차이도 표시하되 서로 다른 seed이므로 같은 문항에 대한 paired test로 취급하지 않는다. 같은 순서의 교대는 장기 시간대 편향을 줄이는 데 도움을 줄 뿐, 순서 효과나 표본 차이를 제거하지 못한다. 5회는 시작 표본이며 우위가 불확실하면 무승부로 유지하고 추가 비교를 검토한다.

최고점만 고르거나 기존 유리한 단회 결과를 이번5회 평균에 섞지 않는다. 같은 계정의 최종 점수는 마지막 제출이며, 이 순서에서는 C5가 마지막이다. 비교 후 보존 후보 선택과 실제 최종 제출은 별도로 판단한다.
