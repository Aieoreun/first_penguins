# R8 개선 실험

사용자가 B `jh_r7_binary_guard`를 우선 후보로 채택한 뒤 추가 실험을 요청했다. 시작 계정 사용량60%/잔여40%, 새 실험 중단 기준은 **잔여25%**다. R7 중단 표식은 과거 이력으로 유지하고 R8은 별도 이름으로 기록한다. 기존 A/B, 주최측 평가기, 교재, 환경변수, 비스트리밍 및 요청 전체 시간 제한을 유지한다. 실제 제출 비교는 사용자 요청으로 종료했다.

기존 제출 기록 체크포인트: ace78cc. 새 실제 제출 집계와 개발 점수는 분리하며 미공개 요청·정답은 수집하지 않는다. 이번 실험은 기존 공개 파생 자료와 승인된 수작업 교재 진단을 사용한다. 같은 자료를 반복하므로 독립 홀드아웃으로 주장하지 않는다.

## 시작 가설

1. 가드: 별도 이진 MLP의 초기값·너비·규제와 확률 평균을 비교하면 차단/허용 경계의 오차를 줄일 수 있다. 기존 grouped OOF와 같은 적용 범위에서 먼저 비교하고, 유망 후보만 동일한 GPT fallback 재생 및 전체 서버로 검증한다.
2. 튜터: 교재 사실과 질문의 값을 구조화해 짧게 구분하면 교재 예시의 금액을 잘못 복사하는 오류와 근거 없는 수치 생성을 줄일 수 있다. 기존 직접 설명8초 후보와 출처 고정 단계부터 비교하고 일반 튜터·혼합 부하로 확인한다.

두 변경은 독립적으로 측정하고 유망할 때만 결합한다. 각 실행의 점수·오류·시간과 실패한 가설도 기록한다. 최종 후보의 자동 교체와 원격 push는 하지 않는다.
