## 주의할 점

- HTTP·형식·채점 오류는 6회 모두 0. 하지만 내부 오류 요청은 튜터 30/600, 가드 54/600이었다. 원본의 부분 결과·기본값 처리로 HTTP 200이 반환된 경우를 포함한다.
- 입력 오차단은 가드 각 14/12/11개. 높은 전체 점수가 입력 문제가 해결됐음을 의미하지 않는다.
- 학습형 분류기 제외 외 원본 서버·검색·판정 프롬프트·투표·실패 기본값·튜터 생성은 유지했다. 원본 공개 예시도 수정하지 않았다.
- 6회 모두 코드·KB·색인 해시 유지, 전체 응답 30초 초과 0, 임베딩 사용 확인, 임시 서버 종료 확인.
- 공개 데이터 성능이며, 비공개 공식 성능 또는 이전 버전 대비 인과적 개선을 확정하지 않는다. 이전 버전을 이번에 다시 평가하지 않았다.
