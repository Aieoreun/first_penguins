# ph — 작성 필요 작업 기록

각자 작업하며 남기는 설계 메모·실험 결과·인수인계를 둔다. 공용 자료는 `docs/ot/`.

## 가드레일 실험 기록 기준

- 실험마다 [실험 목록](guardrail/experiments.md)에 한 줄을 추가하고 `guardrail/experiments/`에 상세 문서를 하나 만든다. 실험 이름에 상세 문서 링크를 건다.
- 목록에는 목적, 실험 이름, 날짜, 코드 커밋, 가드 점수와 평가 출처, 평가 문항 수, 핵심 변경 사항을 적는다.
- 실험 코드를 커밋하고 그 코드로 평가한 뒤, 평가한 코드의 짧은 커밋 해시를 목록과 상세 문서에 기록한다. 기록 문서는 별도 커밋으로 남긴다. 평가 시 커밋되지 않은 코드가 포함됐다면 그 사실을 명시한다.
- 점수와 실험 내용을 받으면 목록과 상세 문서를 갱신하고 기록을 커밋해 작업 브랜치에 푸시한다.
- 상세 문서에는 실험 목적, 추가·수정·삭제한 가드레일, 평가 결과와 제공된 범주별 진단 등 세부 데이터를 기록한다.
- 날짜, 평가 출처, 코드 버전 등 제공되지 않은 정보는 추측하지 않고 `미상`으로 표시한다.
- 운영진 제출 결과는 공용 [제출 기록](../submissions.md)에도 남긴다.
- 채점 요청과 답변 본문은 기록하지 않는다. 공개 세트 문항 ID와 틀린 항목은 기록할 수 있다 (`SPEC.md` §8).
